# 游戏活动日历

一个单页游戏活动日历应用，实时追踪 6 款游戏的活动信息。

## 支持的游戏

| 游戏 | 数据来源 |
|------|----------|
| 原神 | 米游社 API |
| 星穹铁道 | 米游社 API |
| 绝区零 | HoYoLAB 社区 API |
| 鸣潮 | 库街区 API |
| 明日方舟 | 鹰角网络 API |
| 终末地 | end.wiki 第三方站点 |

## 已有功能

- 每天 05:00 和 12:00 自动抓取活动数据
- 按游戏筛选，3 个以上活动自动折叠
- 分组 / 全局时间线两种视图切换
- 暗色模式切换，偏好自动保存
- 紧急程度标识（≤3 天 / ≤7 天）
- 进行中活动的进度条
- 点击卡片查看详情弹窗（含横幅图）
- 所有图片缓存到服务器本地
- 移动端触控适配

## 暂未支持 / 计划中

- 推送通知（即将结束提醒）
- 活动加入日历（iCal 导出）
- 多语言支持

## 技术栈

- **后端：** Node.js, Express, TypeScript
- **前端：** 原生 JS, CSS（无框架）
- **数据：** JSON 文件存储

## 部署

```bash
docker compose up -d
```

绝区零和终末地需要代理访问数据源。
